# Debug challenge (about 15 minutes, in pairs)

This shop has **6 bugs**. Each one stops it working, and fixing one reveals the next.

1. Run `npm install express`, then `npm run dev`.
2. Read the **first** line of the error. Find the file and line number.
3. Fix one bug at a time and run again.
4. For every bug, add a row to your error log: the error message, the cause and the fix.
5. The shop works when `http://localhost:3000` lists three products.

Rules: do not delete code you do not understand, and explain each fix to your partner before you type it.
